← 选择左侧 image 查看导入符号

fishhook 只能改导入符号表 —— 即本 image 调用其它 dylib 导出的符号。凡在此出现的, 都是 fishhook 候选; 被静态链接进主二进制的符号不在导入表里, fishhook 无法拦截, 需改用 inline hook。

若目标通过 dlsym("CCCrypt") 拿函数指针再调用, 不走 import slot; 本插件另 hook dlsym 本身, 在解析时把已知符号重定向到 wrapper 并记录日志 —— 但注入前已缓存的指针无法追溯。

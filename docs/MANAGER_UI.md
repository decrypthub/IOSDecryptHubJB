# IOSDecryptHubJB 手机 Manager UI 规格

日期：2026-10-25。状态：交互规格，尚未实现新版页面。架构正本：[PRODUCT_ARCHITECTURE.md](./PRODUCT_ARCHITECTURE.md)。

## 1. Android 参考与 iOS 落地

已核对 Android 项目 `device/MAP.md`、`ui/home/HomeScreen.kt`、`ui/scope/ScopeScreen.kt`、`HookConfigScreen.kt`、`core/ScopeConfig.kt` 与 `ScopeDraft.kt`。

参考状态优先、逐应用 scope、独立配置详情、前台刷新、保存失败保留编辑状态、进程停止/重启入口。视觉采用 iOS 原生导航、列表、开关、搜索和 SF Symbols，支持浅色/深色与动态字体；不使用 emoji 图标，不复制 Android 的证书或 ART/JNI 功能。

## 2. 信息架构

底栏三项：**首页 / 应用 / 设置**。应用详情由应用行进入，记录详情可打开设备 Web 页面。

### 首页

按以下顺序显示：

1. 服务状态：正在运行 / 正在启动 / 不可用 / 当前越狱环境不可用，以及可操作的错误说明。
2. 已安装整包版本、daemon 运行版本与 Agent 版本不一致提示。
3. 已启用应用数、在线目标进程数、采集健康与丢失摘要。
4. 设备服务地址：复制、打开 Web、MCP 接入说明。
5. 可用更新与打开包管理器入口。

服务不可达时保留旧数据的“上次更新时间”，禁止显示伪造的“正常运行”。不让首页成为几十项调试字段的展示板。

### 应用列表

- 顶部搜索应用名 / bundle ID，筛选“全部”“已启用”“运行中”。
- 应用行：图标、名称、bundle ID、注入开关、实际状态短句。
- 开关操作后显示保存中；保存失败恢复到服务确认的值并显示原因，不让乐观 UI 永久冒充成功。
- 后台刷新不能覆盖用户尚未提交的编辑草稿；revision 冲突给出服务当前值。
- 开关配置与当前进程是否已加载分别显示，例如“已开启 · 待重新启动”“已关闭 · 旧进程仍驻留”。
- 点击行进入详情，开关自身仅改变注入范围，不自动结束目标。

### 应用详情

由上到下：应用与版本 → scope/生效状态 → 能力配置 → 运行进程 → 查看记录 → 诊断。

能力配置采用基础采集与高级功能两组。基础包括加解密、网络、文件、Keychain、动态加载；高级项按实际能力显示 Inline / 函数 Trace / 指令 Trace。未实现或当前设备不支持的项说明原因，不出现可以打开却永远无效的开关。

Inline / Trace 是具体观察任务，不在“启用注入”时自动对全应用、全指令布防。页面的逐应用设置决定允许/默认策略，实际目标、范围和预算由任务接口明确指定。

进程行显示进程名、PID、启动代际、Agent 版本和连接状态；提供“停止应用”“重启并应用配置”。执行时说明会中断该 App 的当前操作，点击即构成用户的明确动作。不得操作 Manager、daemon 或系统关键进程。

### 设置

- 全局注入开关，关闭时保留应用选择。
- 存储与采集限额、清理/导出与诊断。
- 服务状态、重启服务、Web / MCP 地址。
- 唯一正式源地址、复制/添加源说明、候选包版本、打开包管理器更新。
- 关于与组件版本；区分安装版本和在线进程版本。

不增加单独下载 dylib、选择引擎文件、覆盖二进制或重复执行升级脚本的产品流程。

## 3. 必须覆盖的页面状态

| 情况 | UI 反馈 |
|---|---|
| 服务首次启动 | 正在启动，可重试；不是空应用列表 |
| 服务不可达 | 保留最后快照并明确离线，不允许伪保存成功 |
| 应用清单为空 | 显示空态与刷新，不等同于接口错误 |
| 开启但目标已在运行 | 配置已保存，需重启；提供明确操作 |
| 关闭但 Agent 无法联络 | 后续不再注入，当前停止采集未确认，需重启 |
| 更新后目标仍旧引擎 | 已安装新版、该进程仍旧版，需重启目标 |
| scope 保存冲突 | 保留编辑并重新读取当前 revision |
| 更新源未配置 | 正式发布渠道尚未配置，不展示虚构更新结果 |
| 存储或事件预算耗尽 | 显示丢失/截断和可调整项，不能显示完整捕获 |

## 4. UI 验收

最小闭环：安装 deb → 首页确认服务 → 应用页搜索并启用 A → 用户重启 A → 显示在线 Agent → 查看采集 → 关闭 A → 显示真实驻留状态 → 重启 A → 不再加载 Agent。

还需验证动态字体、长中文名/bundle ID、浅深色、搜索无结果、服务重启、应用卸载/重装、更新后的状态恢复。截图和交互实测通过之前，不以“页面能编译”宣称 UI 完成。

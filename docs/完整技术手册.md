## 1. 产品定位与能力边界

### 1.1 一句话定位

**免越狱的 iOS 进程级运行时分析平台** = hook 引擎 + Web 面板 + MCP 服务 + 脱壳 + PC 端网关。

### 1.2 核心用户场景

| 场景 | 能力 |
|------|------|
| 安全研究员 | 实时捕获 CommonCrypto / SecKey / OpenSSL EVP 的密钥、IV、明文、密文 |
| 逆向工程师 | MCP 反汇编、xref、函数调用图、ObjC runtime 查询 |
| AI Agent | 通过 `idh mcp` stdio 网关远程调用设备上 40+ 分析工具 |

### 1.3 能力位（`dh_capability`）

编译期变体 + 运行时能力通过 `dh_capability_bits()` 暴露，MCP `get_capabilities` 为 AI 握手入口：

| 能力位 | 含义 |
|--------|------|
| `DH_CAPBIT_HOOK_IMPORT` | fishhook 改 GOT / 惰性符号指针 |
| `DH_CAPBIT_HOOK_METHOD` | ObjC method swizzle |
| `DH_CAPBIT_UNPACK` | Mach-O 运行时脱壳 |

**明确不做**：inline hook、trampoline 生成、DBI（Frida Stalker / QBDI）、越狱框架 hook API（`MSHookFunction` / `%hook`）。

### 1.4 数据流总览

```
注入载体 (TrollStore patch / 越狱 loader / DYLD_INSERT)
    ↓ dlopen / LC_LOAD_DYLIB
constructor (main.m)
    ↓ 预热 → 配置 → 装 hook → HTTP/MCP → 悬浮窗
Hook 函数 (hooked_*)
    ↓ dh_capture_event / DHLogStore.append
DHLogStore（内存桶 + 落盘 + 噪点桶）
    ↓
HTTP /api/*  +  MCP /api/mcp  +  Web 面板
    ↓
idh 网关（HTTP MCP → stdio MCP）→ AI 客户端
```

## 3. 三种注入变体

| 变体 | `DH_VARIANT` | 注入载体 | 门控 | 产物 |
|------|--------------|----------|------|------|
| `dev` | 0 | 开发者手动（`insert_dylib` / `DYLD_INSERT_LIBRARIES`） | 无 | 裸 dylib |
| `trollstore` | 1 | 管理器 App patch Mach-O | per-app Toggle | IPA + dylib |
| `rootless` | 2 | ElleKit 加载器 | Settings + 应用选择器 | rootless/roothide deb |

三条路线**共享同一份 `src/` 核心**，仅编译宏 `DH_VARIANT` 区分变体标识；核心不得引用 TrollStore patch 逻辑、越狱路径或 daemon。

### 3.1 巨魔路线（TrollStore）

- 不需要 root，不依赖 `/var/jb`
- 管理器向目标主二进制插入 `LC_LOAD_DYLIB`：`@executable_path/decrypt_helper.dylib`
- 复制 dylib 到目标 `.app/` 目录
- CoreTrust bypass（`ct_bypass`）+ `ldid` 伪签名 + `chown 33:33`（installd 属主）
- Patch 逻辑纯 C：`app-trollstore/IOSDecryptHubTS/macho_patch.c`

### 3.2 越狱路线（rootless / roothide）

- ElleKit **仅作 dylib 加载器**，不使用其 hook API
- 薄加载器 `loader.m`：读偏好 → `dlopen` 主 dylib
- 主 dylib 路径：`/var/jb/usr/lib/IOSDecryptHub/decrypt_helper.dylib`（或从 loader 路径推导）
- 私有仓 `make deb`：编译 dylib → 拷入 `IOSDecryptHubJB/vendor/dylib/` → 调用开源仓打包

### 3.3 开发者路线（dev）

- `make` / `make mac` / `make sim` 用于本地灰度
- macOS 变体可浏览器访问 `http://127.0.0.1:8088` 验证 HTTP/MCP

## 4. 架构铁律与设计决策

### 4.1 为什么是 fishhook + swizzle

免越狱侧载拿不到 `dynamic-codesigning` entitlement，内核拒绝 RWX / 可执行内存分配。因此：

| 目标 | 技术 | 原理 |
|------|------|------|
| C 函数 | fishhook | 改写 Mach-O 导入符号指针（GOT / chained fixups） |
| ObjC 方法 | method swizzle | 改写 runtime IMP |

两者只改指针，不生成机器码，在非越狱环境可行。

### 4.2 fishhook 双路径

1. **经典路径**：`__DATA` / `__DATA_CONST` 的 `S_LAZY_SYMBOL_POINTERS` / `S_NON_LAZY_SYMBOL_POINTERS`
2. **Chained fixups**（iOS 15+ / arm64e）：`LC_DYLD_CHAINED_FIXUPS`，支持 `DYLD_CHAINED_PTR_64`、`ARM64E`、`ARM64E_USERLAND`、`ARM64E_USERLAND24`
3. **arm64e PAC 感知**：strip 原始指针、按 key/diversity 重签名
4. **`__AUTH_CONST` 段**：authenticated GOT 扫描

两条路径并行执行，覆盖混合格式 Mach-O。

### 4.3 不崩溃原则

- 不可信内存读：`vm_read_overwrite` 或 `@try/@catch`
- hook 内禁止网络/文件 I/O（除记录路径所必需的最小操作）
- 内存分配失败必须检查；日志/网络失败静默降级
- constructor 启动顺序**不可调换**（见 §5）

### 4.4 服务边界

- HTTP + MCP 共用 `0.0.0.0`，端口 **8088–8108** 自动回退
- MCP 端点固定 `POST /api/mcp`（Streamable HTTP，非 WebSocket）
- **无身份认证**，仅限可信局域网
- **不做设备自动发现**：PC 端 `idh connect <IP>:8088` 手动指定

### 4.5 为什么 MCP 复用 8088

注入场景每多开一个端口就多一分被检测风险；Streamable HTTP 与 REST API 同进程复用监听。

### 4.6 为什么 idh 存在

AI 客户端（Codex / Claude Desktop）主要支持 stdio MCP；设备上是 HTTP MCP。`idh mcp` 做协议桥接。

## 5. dylib 启动流程

入口：`src/core/main.m` 的 `__attribute__((constructor)) dh_bootstrap`。

### 5.1 严格顺序

```
1. 预热 Foundation
   DHTimestampNow()          → 触发 NSDateFormatter locale 懒加载
   DHCallStackFiltered()     → 触发 backtrace/dlopen 懒加载

2. 诊断与配置（装 hook 前）
   dh_diag_set_dir(Documents)
   dh_capture_load(.dh_capture.conf)
   dh_noise_load(.dh_noise.conf)
   dh_spoof_load(.dh_spoof.conf)

3. dh_install_all_hooks()   → 13 类 hook（见 §6）

4. dh_http_start()           → HTTP + MCP 服务

5. UI 后置
   UIApplicationDidFinishLaunching → dh_ui_install_floating()
   + 0.8s dispatch_after 兜底（部分 App 已存在 UIApplication）
```

### 5.2 预热必要性

若不在装 hook 前预热，`hooked_open` 内记录日志触发 `NSDateFormatter` 懒加载 → 再次 `open` → 与 `dh_in_hook` 标志形成双保险外的递归风险。

### 5.3 安装的 Hook 模块顺序

```objc
dh_install_digest_hooks();
dh_install_hmac_hooks();
dh_install_symmetric_hooks();
dh_install_asymmetric_hooks();

dh_install_evp_hooks();
dh_install_file_hooks();
dh_install_system_hooks();
dh_install_keychain_hooks();
dh_install_env_hooks();
dh_install_spoof_objc_hooks();
dh_install_dyld_hooks();
dh_install_network_hooks();
```

## 6. Hook 技术栈

### 6.1 命名约定

| 前缀 | 用途 |
|------|------|
| `dh_` | 核心引擎 API |
| `hooked_` | hook 替换函数 |
| `orig_` | 原始函数指针 |
| `DH` | ObjC 类型（`DHLogEntry` 等） |

### 6.2 重入守卫

1. **线程局部 `dh_in_hook`**：hook 内触发的系统调用跳过二次记录
2. **constructor 预热**：消除懒加载递归源头
3. **`NSRecursiveLock`**：`DHLogStore` 写入路径防自锁死

### 6.3 dlsym 重定向表

`dh_dlsym_redirect.c`：登记所有 fishhook 的符号名 → hook 函数指针。`hooked_dlsym` 优先返回 hook wrapper，使 App 通过 `dlsym` 动态解析时仍走观测路径。

**例外**：OpenSSL EVP 不登记 dlsym 重定向——OpenSSL 3 provider 初始化会 `dlsym` 自身 EVP 符号，重定向会破坏 provider。

### 6.4 安装后自检（fail-loud）

CommonCrypto 类 hook 安装后检查 `orig_*` 是否为 NULL；Security.framework 可能延迟加载，SecKey* 不做安装时自检。

### 6.5 符号表枚举（`dh_symtab.c`）

运行时解析 `LC_SYMTAB` + `__LINKEDIT`，枚举 undefined external 符号——与 fishhook 可 rebind 集合一致。用于 Web `/api/symbols` 和 MCP `list_imports`。

## 7. 抓取管线与日志系统

### 7.1 C/ObjC 桥接

```c
// dh_capture.c → log_store.m 的 dh_capture_bridge()
dh_capture_event(kind, algo, key, iv, in, out);
```

| 索引 | 枚举 | 说明 |
|------|------|------|
| 0 | `DH_CAP_DIGEST` | MD*/SHA* |
| 1 | `DH_CAP_HMAC` | HMAC-* |
| 2 | `DH_CAP_SYMMETRIC` | AES/DES/3DES/RC4… |
| 3 | `DH_CAP_ASYMMETRIC` | RSA/EC SecKey* |
| 4 | `DH_CAP_KDF` | PBKDF2 |
| 5–10 | `DH_CAP_FILE_*` | open/write/read/mmap/unlink/rename |
| 11 | `DH_CAP_SYS_DLOPEN` | dlopen |
| 12 | `DH_CAP_SYS_DLSYM` | dlsym |
| 13 | `DH_CAP_EVP` | OpenSSL EVP |
| 14 | `DH_CAP_KEYCHAIN` | SecItem* |
| 15 | `DH_CAP_ENV_PROBE` | sysctl/ptrace/stat… |
| 16 | `DH_CAP_NETWORK` | NSURLSession + SSL_* |

持久化：`Documents/.dh_capture.conf`（装 hook 前加载）。

### 7.3 日志分类（`DHCategory`）

| 值 | 分类 |
|----|------|
| 0 | Digest |
| 1 | HMAC |
| 2 | Symmetric |
| 3 | Asymmetric |
| 4 | File |
| 5 | System |
| 6 | Network |
| 7 | Keychain |
| 8 | Other |

### 7.4 DHLogEntry 字段

- `algorithm` / `operation` / `key` / `iv` / `input` / `output`
- `publicKeyInfo`（RSA 公钥摘要）
- `detail`（文件路径、库路径等）
- `timestamp` / `timestampMs` / `threadId`
- `callStack`（已过滤系统帧与自身帧）
- `seq`（自增序号，导出游标）

### 7.5 DHLogStore 能力

- 线程安全 `append`；按分类内存桶 + 全局暂停
- 噪点桶（与主事件流分离，见 §7.6）
- 落盘滚动：`.dh_log` + 备份段；`maxPerCategory` / `maxLogFileBytes` 可配置
- `processInfo`：pid / 进程名 / bundle / 系统版本 / 设备型号

### 7.6 噪点过滤（`dh_noise`）

- 两个板块：`DHNoiseBoardCrypto`（加解密类）、`DHNoiseBoardSys`（文件+模块）
- 特征串**完全相等**（不区分大小写）时改投噪点桶，不进主事件流
- 持久化：`Documents/.dh_noise.conf`（v2 JSON）

### 7.7 调用栈过滤

`DHCallStackFiltered()` 从 `backtrace_symbols` 剔除系统库与插件自身帧，只保留 App 业务调用链。

## 8. 加解密 Hook 详解

### 8.1 Digest（`hook_digest.m`）

**库**：CommonCrypto（libSystem）

| 符号 | 类型 |
|------|------|
| `CC_MD2` / `CC_MD4` / `CC_MD5` / `CC_SHA1` / `CC_SHA224` / `CC_SHA256` / `CC_SHA384` / `CC_SHA512` | one-shot |
| 上述每种 × `Init` / `Update` / `Final` | 流式 |

MD2/MD4 在新系统可能无导出符号，best-effort，不纳入 fail-loud 告警。

### 8.2 HMAC（`hook_hmac.m`）

| 符号 |
|------|
| `CCHmac` / `CCHmacInit` / `CCHmacUpdate` / `CCHmacFinal` |

流式状态用 `NSMutableDictionary` 按 ctx 指针跟踪 key 与累积输入。

### 8.3 对称加密（`hook_symmetric.m`）

| 符号 | 说明 |
|------|------|
| `CCCrypt` | 一次性加解密 |
| `CCCryptorCreate` / `CCCryptorCreateWithMode` | 流式创建 |
| `CCCryptorUpdate` / `CCCryptorFinal` / `CCCryptorRelease` | 流式更新/结束 |

流式：按 `cryptorRef` 累积 input/output，Final 时落一条完整日志。累积上限 4MB 防 OOM。

### 8.4 非对称（`hook_asymmetric.m`）

**库**：Security.framework（SecKey*）

| 符号 |
|------|
| `SecKeyCreateSignature` |
| `SecKeyVerifySignature` |
| `SecKeyCreateEncryptedData` |
| `SecKeyCreateDecryptedData` |

记录算法 OID、密钥描述、输入输出数据。

### 8.5 KDF（`hook_kdf.m`）

| 符号 |
|------|
| `CCKeyDerivationPBKDF` |

记录 password（作 key）、salt（作 iv）、derived key（作 output）、算法与 rounds。

### 8.6 OpenSSL EVP（`hook_evp.m`）

| 符号 |
|------|
| `EVP_EncryptInit_ex` / `EVP_DecryptInit_ex` / `EVP_CipherInit_ex` |
| `EVP_EncryptInit_ex2` / `EVP_DecryptInit_ex2` / `EVP_CipherInit_ex2` |
| `EVP_EncryptUpdate` / `EVP_DecryptUpdate` / `EVP_CipherUpdate` |
| `EVP_EncryptFinal_ex` / `EVP_DecryptFinal_ex` / `EVP_CipherFinal_ex` |
| `EVP_CIPHER_CTX_ctrl` |

**动态解析**：OpenSSL 可能延迟加载，通过 `DH_EVP_RESOLVE` 宏在首次调用时 `dlsym` 解析原函数。

**不 hook** `EVP_CIPHER_CTX_free`：macOS 实测 fishhook 可能破坏相邻 `CTX_new` GOT 槽。

**不登记** dlsym 重定向（OpenSSL 3 provider 兼容）。

详见 `docs/EVP-Hook.md`。

## 9. 行为 Hook 详解

### 9.1 文件（`hook_file.m`）

| 符号 | 捕获内容 |
|------|----------|
| `open` | 路径（App 沙箱内文件） |
| `write` / `read` / `pread` | 已跟踪 fd 的内容 |
| `mmap` | 已跟踪 fd 的映射 |
| `close` | 清理 fd 跟踪表 |
| `unlink` / `rename` | 路径操作 |

`dh_is_app_file()` 过滤非 App 相关路径，减少噪声。

### 9.2 系统 / 动态加载（`hook_system.m`）

| 符号 | 说明 |
|------|------|
| `dlopen` | 记录加载的库路径 |
| `dlsym` | 记录符号解析；含重定向结果 |

### 9.3 Keychain（`hook_keychain.m`）

| 符号 |
|------|
| `SecItemCopyMatching` |
| `SecItemAdd` |
| `SecItemUpdate` |
| `SecItemDelete` |

明文 value 存在 `output`；query 摘要 humanize 后写入 `detail`。

### 9.4 环境探测（`hook_env.m`）

| 符号 | 行为 |
|------|------|
| `ptrace` | 反调试：PT_DENY_ATTACH 空转（`dh_spoof_anti_debug`） |
| `csops` | 清 CS_DEBUGGED 标志 |
| `sysctl` / `sysctlbyname` | 观测 + 改机 hw.machine/model |
| `uname` | 观测 |
| `getenv` | 观测 DYLD_* 等 |
| `stat` / `lstat` / `access` / `faccessat` / `fstatat` | 越狱路径隐藏 + 观测 |

### 9.5 网络（`hook_network.m`）

**NSURLSession（ObjC swizzle）**：

- `dataTaskWithRequest:completionHandler:` 等 completion 型任务
- `dataTaskWithRequest:` / `uploadTaskWithRequest:fromData:` 非 completion 型
- `NSMutableURLRequest setHTTPBody:` 捕获 body
- `NSURLSessionTask resume` 兜底 delegate 型任务

在 `resume` 时合并 method/url/headers/body 落日志。

**TLS（fishhook，best-effort）**：

| 符号 |
|------|
| `SSL_write` |
| `SSL_read` |

使用 `void*` 占位 SSL 类型，避免链接 libssl。

### 9.6 dyld 隐藏（`hook_dyld.m`）

| 符号 | 策略 |
|------|------|
| `_dyld_get_image_name` | 命中隐藏清单 → 返回 `/usr/lib/libSystem.B.dylib` |
| `dladdr` | 同上，抹掉 `dli_fname` |

「改名不删项」：不改 `_dyld_image_count`，避免索引错位。

### 9.7 ObjC 伪装（`hook_spoof_objc.m`）

| 类 / 方法 | 功能 |
|-----------|------|
| `UIDevice systemVersion` / `name` / `identifierForVendor` | 改机 |
| `NSProcessInfo operatingSystemVersion` | 改机 |
| `ASIdentifierManager advertisingIdentifier` | IDFA 伪造 |
| `UIApplication canOpenURL:` | 隐藏 cydia:// 等 scheme + 观测 |

使用单例真实类 swizzle（处理类簇/私有子类）。

## 10. 伪装 / 反调试 / 注入隐藏

配置中心：`dh_spoof`，持久化 `Documents/.dh_spoof.conf`（JSON）。

### 10.1 越狱隐藏（`jb`）

- 总开关 + 路径清单 + URL scheme 清单 + image 名清单
- `dh_spoof_jb_should_hide_path()`：热路径 volatile 早退 + 集合匹配
- 默认含常见越狱路径与注入框架标记

### 10.2 反调试（`anti`）

- `ptrace(PT_DENY_ATTACH)` 空转
- `sysctl` 清 `P_TRACED`
- `csops` 清 `CS_DEBUGGED`

### 10.3 改机（`device`）

- 默认关（避免误伤）
- 可伪造：`hw_machine` / `hw_model` / `os_version` / `device_name` / `idfv` / `idfa`
- `dh_spoof_device_randomize()`：内置真实机型表随机

### 10.4 观测 vs 改写

- 环境探测默认**只观测**（记日志）
- 改写（隐藏/伪造）由 spoof 开关控制

## 11. 运行时动态 Hook（thunk-bank）

文件：`dh_thunk.m` / `dh_thunk.h`

### 11.1 设计目标

让 AI 在运行时对**任意导入 C 符号**或**任意 ObjC 方法**装只读 hook：记录参数寄存器快照 + 调用栈 + 命中次数后原样转发。

### 11.2 机制

- 预编译 128 个固定 8 字节 thunk（`movz x17, #slot; b trampoline`）在 dylib 自有 `__TEXT` 段
- **非 JIT**：巨魔/免越狱可用
- 装 hook = 将 GOT 项或 IMP 改指向 `thunk[i]`
- Trampoline 保存 x0–x8 / q0–q7 / lr → C handler 记录 → 尾调用 `g_dh_thunk_orig[slot]`

### 11.3 API

| 函数 | 说明 |
|------|------|
| `dh_thunk_install_import(symbol, label)` | fishhook + thunk |
| `dh_thunk_install_method(class, selector, classMethod)` | swizzle + thunk |
| `dh_thunk_disable(slot)` | 原子关闭记录 |
| `dh_thunk_list(out, max)` | 枚举已装 hook |

### 11.4 MCP 暴露

- `hook_import` / `hook_method` / `list_hooks` / `unhook`

## 12. 二进制分析与 Capstone

### 12.1 Capstone 嵌入

- 版本 **5.0.1**，源码嵌入 `src/core/capstone/`
- 仅 ARM / AArch64 架构
- 产物 dylib 约 **2MB**
- 必需宏：`CAPSTONE_USE_SYS_DYN_MEM`、`CAPSTONE_HAS_ARM`、`CAPSTONE_HAS_ARM64`

### 12.2 analysis.m 能力

- `vm_read_overwrite` 安全读进程内存
- Mach-O 镜像枚举（dyld + bundle 过滤）
- `LC_FUNCTION_STARTS` 函数边界
- ARM64 结构化反汇编：operands、寄存器读写、跳转目标
- `MOVZ/MOVN/MOVK` 常量重建（线性范围内，非 CFG）
- Xref 扫描：`find_xrefs` / `find_string_refs` / `find_selector_refs` / `find_function_refs`
- ObjC runtime：`objc_resolve_imp` / `find_objc_methods`

### 12.3 函数归属（tier-1.5）

优先 `LC_FUNCTION_STARTS` → strip 后 `sub_<runtime>`；`dladdr` 仅作低置信度回退。

### 12.4 大镜像分页

单次最多扫描 48MB `__text`；`scan.has_more` + `next_scan_offset` 分页续扫。
